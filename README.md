# Snake_OpenGL
Snake videogame developed in C++ using the framework OpenGL<br />
Steps to build and run the project: <br />
- clone the repository<br />
- git submodule update --init --recursive<br />
- mkdir build<br />
- cd build/<br />
- cmake -DCMAKE_POLICY_VERSION_MINIMUM=3.5 ..<br />
- cmake --build .<br />
- cd bin/Debug/<br />
- ./main.exe<br />
